# Cat House

一个基于 Vue 3 + TypeScript + Vite 的虚拟猫屋项目。

## 技术栈

- **UI 框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **语言**: TypeScript
- **测试框架**: Vitest + Vue Test Utils
- **状态管理**: Pinia (待集成)
- **渲染引擎**: HTML5 Canvas (待集成)
- **物理引擎**: Matter.js (待集成)
